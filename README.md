# ABI Kaluvan — сайт и клиент раздельно

Помощник для торговца (Field Merchant) в *Arena Breakout: Infinite*: по звуку перетаскиваемого груза, размеру, надписи и цене показывает, что может быть внутри, и шанс красного предмета.

Это переработка [neverh8me/abi-kaluvan](https://github.com/neverh8me/abi-kaluvan) v1.3.5. Здесь проект разделён на две независимые части.

| Папка | Что это | Где работает |
|---|---|---|
| [`web/`](web/README.md) | Сайт: статичные HTML/JS. Всё распознавание (сетка, текст, звук, шансы) идёт в браузере | Любой веб-сервер (ваш Linux-сервер) или `localhost` |
| [`client/`](client/README.md) | Клиент на C# (.NET 10): захватывает звук только процесса игры и кадры только её окна, отдаёт их сайту по WebSocket | Игровой ПК с Windows |

```
[Linux-сервер]  nginx/caddy раздаёт web/ по HTTPS
       │  страница
       ▼
[Игровой ПК]  браузер ──ws://localhost:8777──►  AbiKaluvan.Client.exe ──► звук и окно UAGame.exe
```

Клиент необязателен. Без него сайт сам попросит поделиться экраном с системным звуком (Chrome/Edge на Windows: «Весь экран» + «Поделиться системным звуком»). Но тогда в звук попадает всё: Discord, музыка и т. д.

## Что изменилось по сравнению с оригиналом

- Сайт и клиент — отдельные проекты. Клиент больше не раздаёт файлы сайта, а сайт берёт адрес клиента из `web/config.js`.
- Клиент — обычный проект .NET (`.csproj`), собирается в `.exe`. Нет `start.bat`, нет PowerShell с `-ExecutionPolicy Bypass`, нет компиляции C# на лету.
- **Исправлена уязвимость:** клиент принимает подключения только от `localhost` и сайтов из `allowedOrigins`. В оригинале любой открытый сайт мог получить картинку и звук игры.
- Убраны автообновление с GitHub, создание ярлыка на рабочем столе и отправка ваших покупок на сервер автора (Cloudflare Worker). Свои покупки хранятся только в браузере. Общая база покупок оригинала по-прежнему читается (только чтение), это можно отключить в `web/config.js`.

## Быстрый старт на одном ПК

```bash
cd client
dotnet run -c Release
```

```bash
cd web
python -m http.server 8080
```

Откройте `http://localhost:8080/`, переключите игру в «Окно без рамки» и нажмите **Start catching**. Подробности — в [web/README.md](web/README.md) и [client/README.md](client/README.md).
