# Merchant Ear Client (`client/`)

[English](README.md) · **Русский**

Консольное приложение для Windows на .NET 10. Захватывает звук только процесса игры, кадры только её окна и положение курсора и отдаёт их сайту по WebSocket. У каждой страницы своя очередь: медленная вкладка не тормозит захват и других. Сайт (`web/`) встроен в exe и открывается по адресу `http://localhost:8777/`; при запуске exe сам открывает его в браузере по умолчанию, а повторный запуск просто открывает страницу уже работающего.

| Файл | Что делает |
|---|---|
| `src/Capture.cs` | Захват звука процесса через WASAPI process loopback (как OBS и Discord) снимки окна игры через GDI, положение курсора. Память игры не читается, процесс не открывается |
| `src/Server.cs` | `ws://localhost:8777/audio` (48 кГц моно float), `ws://localhost:8777/screen` (JPEG правой половины окна, до 30 кадров/с, плюс курсор), `GET /status` |
| `src/SiteFiles.cs` | Встроенный сайт; `config.js` создаётся на лету, чтобы страница подключалась к тому же порту |
| `src/Peer.cs` | Одна подключённая страница: свой поток отправки и очередь |
| `src/Settings.cs` | Настройки и проверка, каким сайтам можно подключаться |
| `appsettings.json` | Порт, имя процесса игры, разрешённые сайты |

## Требования

- Windows 11 или Windows 10 сборки 20348 и новее (нужен захват звука отдельного процесса).
- .NET 10 SDK для сборки. Релизному `.exe` ничего не нужно: среда .NET внутри.
- Игра в режиме «Окно без рамки» (Borderless). В полноэкранном режиме кадр будет чёрным.

## Сборка и запуск

```bash
dotnet run -c Release
```

Один файл `MerchantEar.exe` (со средой .NET, сжатый, около 48 МБ) в папку `publish/`:

```bash
dotnet publish -c Release -o publish
```

Релизы собирает GitHub Actions (`.github/workflows/release.yml`), когда в репозиторий отправлен тег `v*`.

## Настройки

`appsettings.json` рядом с `.exe`:

```json
{
  "port": 8777,
  "exe": "UAGame",
  "allowedOrigins": ["https://abi.example.com"]
}
```

- Страницы с `localhost` и `127.0.0.1` разрешены всегда. Любой другой сайт получит отказ 403, и это будет видно в окне клиента.
- Файл необязателен: без него берутся значения выше (без дополнительных сайтов).
- Те же параметры можно задать в командной строке: `--port 8799 --exe UAGame --origin https://abi.example.com`; `--no-browser` — не открывать браузер.
- Встроенный сайт всегда подключается к тому порту, с которого открыт. Если раздаёте `web/` отдельно и меняете порт, поменяйте и `clientUrl` в `web/config.js`.

Проверить, что клиент работает:

```bash
curl http://localhost:8777/status
```
